# Publication checklist

- [ ] Production script added and tested from a clean host
- [ ] No credentials, keys, tokens, or private addresses
- [ ] No customer, account, or internal project identifiers
- [ ] Employer and university publication requirements confirmed
- [ ] Duration values normalized to seconds
- [ ] Goodput recalculated from bytes and normalized duration
- [ ] Compression ratio or transmitted bytes captured
- [ ] All released rows include documented validation status
- [ ] Environment and software versions recorded
- [ ] Analysis notebook recreates every released table and figure
- [ ] CITATION.cff URL, version, release date, and DOI updated
- [ ] Release tag created and archived
- [ ] README documents limitations and supported environments
